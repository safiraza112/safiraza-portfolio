# SAFIRAZA | Student Portfolio

A responsive, multi-page portfolio website for **Safi Raza**, an undergraduate Software Engineering student at Sindh Madressatul Islam University (SMIU), Karachi. It presents my background, skills, projects and contact details in one clean, fast website.

**Live site:** https://safiraza112.github.io/safiraza-portfolio/

---

## About this project

This portfolio was built as a student project to show my skills as a software engineer in a professional format. It is written in plain HTML, CSS and JavaScript, so it loads quickly, needs no build tools, and can be hosted for free on GitHub Pages.

## Pages

| Page | File | What it contains |
|------|------|------------------|
| Home | `index.html` | Introduction, code-style profile card, featured projects, skills overview |
| About | `about.html` | Summary, skills, coursework, soft skills, education timeline, resume download |
| Projects | `projects.html` | Detailed cards for each university project with tech tags and source links |
| Contact | `contact.html` | Email, GitHub, LinkedIn and a message form |

## Features

- **Responsive design:** works on phones, tablets and desktops
- **Light and dark theme:** toggle button, and it follows the device setting by default
- **Mobile navigation menu** with keyboard-accessible controls
- **Downloadable resume** (PDF)
- **Contact form** that opens the visitor's email app with the message filled in
- **Accessible by design:** semantic HTML, image alt text, visible keyboard focus, and reduced-motion support
- **SEO basics:** page titles, meta descriptions, favicon and social preview tags
- **No dependencies:** no frameworks, no build step

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/safiraza112/safiraza-portfolio.git
   ```
2. Open the folder and double-click `index.html`, or open it with a local server such as the VS Code **Live Server** extension.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, then click **Save**.
4. After a minute or two, the site is live at `https://safiraza112.github.io/safiraza-portfolio/`.

## Customize

- Change colors in the `:root` block at the top of `assets/style.css`.
- Replace images in `assets/images/` and update the `src` paths in the HTML files.
- Update the resume by replacing `assets/Safi-Raza-Resume.pdf`.
